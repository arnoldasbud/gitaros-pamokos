# Darbo taisyklės šiame repozitorijoje

- Atsakinėkite naudotojui lietuviškai.
- Programėlė yra vienas failas `index.html` (be priklausomybių), skelbiama per GitHub Pages: https://arnoldasbud.github.io/gitaros-pamokos/
- **Kiekvieną kartą keičiant `index.html`, padidinkite `APP_V`** (formatas `METAI-MĖN-DIENA` + raidė, pvz. `2026-11-21b`). Pagal jį programėlė pasiūlo atsinaujinti ir rodo versiją apačioje.
- **Padarę pakeitimus, visada iš karto sujunkite PR į `main`** (naudotojo nurodymas 2026-11-21: „padaręs pakeitimus visuomet sujunk“). Klausti nereikia. Po sujungimo patikrinkite, ar „pages build and deployment“ baigėsi sėkmingai.
- Jei projekto aplanke yra `gitara/gitaros-pratybos.html`, atnaujinkite jį tuo pačiu `index.html` turiniu.
