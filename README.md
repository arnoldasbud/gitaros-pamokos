# Gitaros pratybos

Mobili gitaros mokymosi programėlė: 6 etapai po 2 savaites su pratimais, laikmačiu, metronomu, muzikos teorija, tikslais ir grifo natų treniruokliu: programėlė parodo natą ir stygą, mikrofonu patikrina, ar ji teisinga, ir matuoja laiką.

Atidaryti: https://arnoldasbud.github.io/gitaros-pamokos/

Viskas viename `index.html` faile, be priklausomybių. Pažanga saugoma naršyklėje (localStorage).
